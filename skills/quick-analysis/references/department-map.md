# Compact department map

Use this only when a quick skill was invoked directly without a `DEPARTMENT:` line. Pick the one
department whose output best matches the requested deliverable.

| Area | Department |
|---|---|
| Product definition, roadmap | `product-management` |
| Program plan or launch readiness | `npi-program-management` |
| Industrial or UX/UI design | `design-hw` or `design-sw` |
| Physical product engineering | `hardware-engineering` |
| Application code | `software-engineering` |
| Infrastructure or deployment | `platform-infrastructure` |
| Data, model or dashboard | `data-ai` |
| Requirements, architecture, interfaces | `systems-engineering` |
| Engineering tools, PLM, CAD or build tooling | `engineering-systems` |
| Manual, guide or reference | `technical-publications` |
| Factory work | `manufacturing` |
| Suppliers or purchasing | `supply-chain` |
| Conformance or nonconformance | `quality` |
| Project plan and delivery | `project-delivery` |
| On-site service | `field-service` |
| Connected-equipment alarm or NOC | `remote-monitoring` |
| Hazard, incident, exposure or environment | `ehs` |
| Opportunity or customer proposal | `sales` |
| Technical quote, scope or estimate | `sales-applications-engineering` |
| Marketing content | `marketing` |
| Customer case, reply or support | `customer-success-support` |
| Posting-ready accounting workpaper | `accounting` |
| Forecast, budget or financial model | `fpa` |
| Internal IT | `it` |
| Security control, threat or finding | `security` |

If two outputs remain materially different, ask one either/or question. People and Legal work is out
of scope; route only the business portion and flag the rest for the user's qualified owner.
